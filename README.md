# SkyCampus-ECI-Morales

Sistema de drones de reparto de la Escuela Colombiana de Ingeniería (nivel Chimchar, MVP).

## Flujo de ramas (GitFlow)
- `main`: versión estable. Nunca se hace push directo.
- `develop`: integración. Aquí se hace merge de las ramas feature.
- `feature/MoralesZambrano-*`: una rama por funcionalidad, siempre creada desde `develop`.
